# 📁 Linked List Implementations

This folder contains **complete implementations of the Linked List data structure** in three different programming languages:

## 🔧 Contents

### ✅ C - Singly Linked List
- Full implementation of a singly linked list in C
- Operations included:
  - Insert (at beginning, end, and specific position)
  - Delete (by value and by position)
  - Search
  - Count nodes
  - Display all elements
- Well-commented for learning and interview preparation

### ✅ Java - Singly Linked List
- Java-based implementation of linked list with all core functionalities
- Object-oriented structure using `Node` and `LinkedList` classes
- Each method is documented with comments
- Suitable for both beginners and intermediate learners

### ✅ Python - Singly Linked List
- Clean, modular Python implementation using OOP
- All major operations implemented:
  - Insertions
  - Deletions
  - Search
  - Size
  - Display
- Readable and easy-to-understand code with function docstrings

---

## 📘 Usage
Each file is standalone and can be run using the respective compilers or interpreters:
- C: `gcc linked_list.c -o linkedlist && ./linkedlist`
- Java: `javac LinkedList.java && java LinkedList`
- Python: `python linked_list.py`
